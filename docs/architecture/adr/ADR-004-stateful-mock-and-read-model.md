# ADR-004 — Frontend M2, stateful mock và presentation snapshot

06/10/2026 · accepted trong bước 5 · scope-v2/analysis-v2 · supersedes kế hoạch wiring của ADR-002, giữ stack ADR-001 và privacy boundary ADR-003.

Không scaffold app mới hay đổi dependency. React/Router/Vite, tokens, các form/cards/charts, financial selectors và /design được tái dùng. Owner state chuyển sang MockRepository trong module MSW lazy-load riêng. UI dùng AppProvider → services → HttpSyntheticTransport → fetch → MSW → typed operation → domain engine → validated DTO. Auth và chat cũng đi qua network; /demo/* trả 410. Không import fixture hoặc applyCommand vào feature UI.

Chọn một query `getPresentationSnapshot` trả DTO read-only Zod strict, bao gồm toàn bộ dữ liệu nhỏ trong workspace synthetic. UI derive period/scope/charts/detail từ cùng response version bằng pure selectors. Filters, mở dialog/panel, chart table và privacy là local UI; không ép gọi API. Mutation dùng named logical operations; không có generic endpoint ghi lại Store từ client. Resource/report endpoints vẫn được xử lý, validate và kiểm tra bằng tests, AI và công cụ chẩn đoán. Khi dữ liệu thật lớn, chia read models/pagination tại adapter boundary sau PoC; snapshot này không phải quyết định tải mọi financial record tới gateway.

Contract exact-match 1.1.0 thay baseline chưa công bố 1.0.0; bản cũ giữ tại governance/baselines/contracts-step4-v1. Bổ sung read snapshot, CSV template, source evidence/revision, optional Metric.label và CSV mapping signed/debit-credit. Session response bổ sung sessionId bắt buộc cho mock session ownership: đây là migration của identity client cùng app, không tuyên bố tương thích reader 1.0. Production contract cần version major/migration policy trước công bố; đường /__mock/v1 chỉ đánh dấu family mock, không nhận version sai.

MSW 3.0.2 dùng `onUnhandledFrame` theo declaration/package đã khóa: chỉ cho GET nội bộ phục vụ tài liệu/static assets; API hoặc outbound chưa có handler bị error. Không dùng option cũ của MSW2. Một lỗi browser đã phát hiện policy strict toàn frame chặn reload; đã sửa phạm vi và chạy lại regression. Financial commit serialize và rollback khi output schema sai. Idempotency lưu acknowledgement/job, không khôi phục một Store cũ. Preview bind owner/payload/version/TTL; import hoàn tất atomic, poll cùng job.

TanStack Query invalidate cùng prefix workspace sau mutation rồi refetch snapshot; queries staleTime Infinity cho synthetic immutable-until-mutation, retry tự động tắt. Latch ở form/provider ngăn submit đồng thời. Đây là cách dùng [query invalidation chính thức](https://tanstack.com/query/latest/docs/framework/react/guides/query-invalidation), phiên bản package thực tế giữ nguyên lock.

Real mode đóng trước fetch và protected adapter throw SECURITY_TRANSPORT_NOT_VERIFIED. SessionStorage chỉ chứa fake demo profile, opaque synthetic sessionId/challenge; không mật khẩu/code/key thật. Client marker không chứng minh quyền thật. Mock memory mất khi reload; restore tab marker tạo session demo cho repository mới. Không durable backend, Anti-Ops, provider hoặc real AI/security gate được xác minh.
