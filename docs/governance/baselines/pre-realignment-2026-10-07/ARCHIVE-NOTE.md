# Snapshot trước rà soát sản phẩm v3

Tạo07/10/2026; hoàn thiện rà soát08/10/2026. Các file trong thư mục này là bản sao nguyên byte của12 tài liệu trước thay thế; manifest.json chứa SHA256 tại thời điểm sao chép. Không sửa đường dẫn tương đối bên trong các snapshot để giữ nguyên bytes; một số link chỉ có nghĩa ở vị trí gốc lúc snapshot. Các file ở đây không là nguồn yêu cầu hiện hành.

Nguồn hiện hành ở docs/product/prd.md, docs/requirements/srs.md và các tài liệu liên kết từ README gốc. Gate/pass/mock status và thời điểm trong snapshot là lịch sử. Không dùng snapshot như bằng chứng yêu cầu Android/backend/Agent v3 đã triển khai.
