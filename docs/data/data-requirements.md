## Quan hệ, lineage và ràng buộc truy cập

Workspace 1:N accounts/assets/sources/events/cases; asset 1:N holdings; holding 1:N movements; event 1:N entry groups và N:M source records qua evidence. Refund/reversal/replacement liên kết event gốc; import job có selected records/result IDs. Quote liên kết asset identity tương thích, FX pair riêng; snapshot tham chiếu versions của event/entry/holding/quote/scope. Cash observation tham chiếu account và snapshot cùng mốc. Mọi ref kiểm tra workspace trước mutation/read; đường detail/drill-down/Review phải giữ checks, ở M1 chỉ scenario mô phỏng denied.

Lineage tối thiểu: CSV row/raw+parser+mapping → normalized fields → evidence/event → committed effects → snapshot.metric → filter/căn cứ. Quantity: declaration/movement+date → holding; price+FX+unit+date → valuation component → asset subtotal. Category override ghi decision provenance tách source revision; source báo hủy không xóa original. Tính lại snapshot từ cùng version phải cho cùng số; không chart tự cộng độc lập.
