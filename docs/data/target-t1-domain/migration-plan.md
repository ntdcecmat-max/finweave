# Migration và quyền domain — design only

SQL004+ sẽ phân bổ khi viết executable migration. Không sửa001–003, D1/J2/auth/security packages hoặc baselines. Không chạy PostgreSQL trong ARCH-08.

1. Kiểm actual schema/guards/roles bằng disposable syntheticDB. Reconcile opening declarations với sealed opening groups; zero opening không tạo zero-lines hoặc double posting. Legacy ledger có mismatch thì quarantine/report, không tự sinh thêm tiền để cân.
2. Thêm forecast_runs/result_pages và6 composite FKs theo model. Version/state/trials/page-index bounds; page count/index/bytes/digest và all-paths-complete checked ở procedure publish. Unique(workspace,run,pageIndex); indexes run(workspace,state,created_at), result_pages(workspace,run,page_index), references payload IDs. Không index settings/financial JSON cho Ops.
3. payload_objects owner_module=Planning, object_kind=forecast_input/forecast_checkpoint/forecast_page, đúng object_id/run/page/schema/digest. FK chỉ bảo vệ reference existence, không đủ typed ownership; procedure kiểm cả workspace/run và job ticket. Checkpoint state frozen input/model/runtime version, per-trial cursor/residual/RNG index/aggregates; chunks có bounded size. Không lưu run input/result nhạy cảm trong jobs hoặc job_attempts diagnostics.
4. ForecastWorker service profile riêng, per-profile mTLS/MAC; chỉ narrow read frozen input/checkpoint và fenced stage/publish. Không SELECT live ledger rộng, owner auth secrets, Plan/Goal confirm hoặc actual writes. Owner read qua current object authorization; admin không SELECT2bảng mới hoặc payload finance, chỉ sanitized aggregate worker health. DB RLS/SET LOCAL theo ARCH-07.
5. J2 typed registry thêm forecast_run/forecast job, dispatch port executeForecastRun, cancel và recovery fence. Domain run+enqueue atomic; run không có lease/generation authority riêng. Dynamic registry không được nhận arbitrary table/SQL/profile từ client. API enqueue202 không nghĩa completed forecast.
6. Snapshot/history closure pin mọi competing funding dependencies và source/model versions. Read REPEATABLE READ, write workspace anchor và stable lock order. Unique active actual family across revisions cần narrow locked validation cùng event lineage/scope resolution; không giả unique(planning_revision_id,event_id) tự đủ. Group seal/immutability guards và internal ledger purpose uniqueness phải kiểm bằng directSQL negative tests.
7. Publish kiểm tất cả pages/private digests/trials under live ticket+run lock; atomically succeeded. Cancel/revoke/erase/lease expiry thắng stale worker; staged content không serve. Unpinned30d expiration không xóa tombstone/replay identity; pinned refs tới release/erasure. Retention chỉ qua narrow expiry procedure. Erasure dependency inventory ARCH-07 phải bao gồm inputs/checkpoints/pages, snapshots/pins và backups.
8. Upgrade/backfill/cutover, rollback/rollforward, FK/history seal, concurrent allocation/refund/link, interrupted forecast/restore và grants cần behavioral evidence trước bật consumers. Không downgrade fence/version, bỏ guards hay hồi sinh expired results khi rollback. Rebuild cache không là restore authority.
