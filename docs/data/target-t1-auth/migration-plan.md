Validate owner_id match installation.subject_id, collector credentials owner/workspace/device/state/epochs.

Rollforward repair preferred; old read paths/columns giữ tới verified cutover, sau đó explicit contract migration xóa native legacy token_digest reliance. DB restore không mở uploader khi checkpoint unavailable; encrypted replay secrets hết hạn không được resurrect. No real migration approved by this plan.

Restore key/pepper version handling và independent checkpoint không được giản lược thành local auth table cleanup.
