# Bộ đặc tả giao diện FinWeave

08/10/2026 · UI/UX v1.0 theo scope-v3 · thiết kế đích, có cập nhật implementation riêng.

[Bản đồ tài liệu và thay đổi](operational-design-delta.md) là điểm vào hiện hành. Bắt đầu từ [danh mục màn](interface-catalogue.md), [luồng UX](ux-ui-specification.md) và [hành vi màn/form](screen-behavior-specification.md); sau đó đọc phần [Android](android-ui-specification.md), [admin](admin-ui-specification.md), [components](component-specifications.md), [patterns](pattern-library.md), [design system](design-system.md), [auth](authentication-specification.md) và [accessibility](accessibility-requirements.md).

[Đối chiếu yêu cầu và UI acceptance](ui-requirement-traceability.md) nối tới SRS/AI spec. [Báo cáo cập nhật](../execution/ui-documentation-update.md) giải thích phần giữ, bổ sung và thay đổi. [Snapshot bản cũ](../governance/baselines/ui-before-v3-2026-10-08/README.md) giữ lịch sử mock và source APIs.

Trạng thái: đủ đặc tả để dựng wireframe và bổ sung UI có căn cứ; implementation đã có một phần UI/mock theo [báo cáo08/10](../execution/ui-implementation-2026-10-08.md); kiểm tự động hiện hành tại [nghiệm thu frontend](../testing/frontend-acceptance-report.md); native PoC và UAT chưa chạy. [Research plan](research-plan.md), [reference catalogue](reference-catalogue.md) và [validation lịch sử](validation-report.md) không phải chứng cứ các UI mới đã chạy. Các bản mô tả triển khai cũ trong evidence không ghi đè đặc tả đích này.
