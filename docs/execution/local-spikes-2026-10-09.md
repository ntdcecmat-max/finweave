## Thay đổi kiến trúc/implementation cần thiết

1. **Boundary code dùng authority live từ server**, không copy helper spike vào runtime. Pin audited RFC8785/ES256 conversion/Draft2020 validator; proof nonce cùng transaction với rotation/replay marker. Same semantic command retry giữ key/input nhưng fresh proof nonce/requestId. HMAC cert profile không thay typed lease/workspace/generation/epoch checks. Browser Secure host cookie+Origin+CSRF phải kiểm bằng browser HTTPS thật trước tích hợp consumer.
2. **Binding exact API005/native003 tại adapter.** `docs/agent/native-bridge-003.json` đổi revision enums đúng005/003 nhưng description còn nhắc API004. Android docs002/004 là lịch sử. Consumer phải chọn exact current artifact hash, không derive revision từ description/filename cũ. Cần sửa metadata qua revision/sealing workflow ở bước triển khai; task này giữ các bundle đã seal. Không cần thêm API field để bù mismatch này.
3. **Outbox repository tách transport khỏi captured identity.** Native vault/nonce durable reservation/DEK rotation/clock bounds phải implement thực, noBackup DB/WAL/SHM và OEM transfer tests. Retry không reset captured deadline; ACK không retag owner/binding/epoch; server commit checks live revocation, kể cả request được nhận trước revoke. Room, WorkManager và Keystore test là gate độc lập.
4. **Restore coordinator khởi động LOCKED và process finance không mở trước gate.** Ghép witness nonce-bound latest head+chain+max floors với backup inventory/key capsule/oldhost fence/credential invalidation/denied-target scan. AEAD fixture không thay age, local file witness không thay off-host receiver. Bảo đảm keys có authorized decrypt path bên ngoài backup; old password/session/code/device từ backup không tự mở lại. Gate booleans thử hiện chưa là verifier implementation.
5. **Rights/profile eligibility có version tại intake, cache, backup và Agent context.** Product/side/unit/basis/calendar/rights không dùng default đoán. Unknown/date-only/future quote giữ last-good/unknown, không stamp fetchedAt làm quote mới. Provider disabled là trạng thái thật; synthetic/manual provenance khác provider provenance. API/schema mới chỉ cần khi verified rights đòi data/retention ngoài contract hiện có, phải revision có migration.
6. **Model provider là port disabled tới khi có artifact và gate đo.** Orchestrator/Decision/tool budgets/grounding/manual fallback có thể xây với synthetic inputs ngay. Giữ actual commit chỉ owner confirm; tool/schema whitelist không chứng minh prompt injection resistance từ model. Bổ sung bounded process measurements/timeouts/cold-warm và evaluation runner sau pin, không dùng thời gian validator làm model SLO.
7. **Release/drain có gate thực cùng DB fence.** Existing SQL coverage là nền cho coordinator, chưa chứng minh process cũ/APK cũ bị ngăn end-to-end. Restore/retention/alerts cần failure domains và receiver thực; không chứng nhận bằng virtual timestamps, same-host backup hoặc mock alert.

Các điểm trên là addendum implementation/gate, chưa thay T1/schema/budget/feature. Nếu trial thật phát hiện contract/algorithm không đáp ứng thì tạo ADR/schema revision có migration, retest impacted cases; không bỏ feature để né FAIL.
